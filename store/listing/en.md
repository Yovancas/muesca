## Descripción corta
Requires Claude Code. See your Claude Code quota (5-hour and weekly), live sessions and permission requests in a small notch at the top of your screen and in the system tray. Free, with an optional one-time Pro upgrade. Not affiliated with Anthropic.

## Descripción
Requires Claude Code (the CLI or the desktop app) installed and signed in on this PC. Muesca is an independent app for Claude Code: it is not made by, affiliated with or endorsed by Anthropic.

Muesca keeps an eye on Claude Code for you. A small notch at the top of your screen and an icon in the system tray show how much of your quota you have used, when it resets and what each of your Claude Code sessions is doing, so you don't have to switch to the terminal to find out.

FREE
• Real quota for the 5-hour and weekly windows (the same figures Claude Code gets), with reset countdowns and a pace indicator.
• A tray icon whose color and shape change as you approach the limit: readable at a glance and colorblind-safe.
• A panel with quota bars, estimated spend by model (calculated on your PC from your transcripts) and usage charts.
• Alerts when you cross 25, 50, 75 and 95 %, or when your pace would run out before the reset.
• A notch with quota rings and the state of each Claude Code session: working, waiting for you or done.
• A Usage page with every number, and a focus timer (pomodoro).
• A welcome wizard, an interactive tutorial, light and dark themes, reduce motion and 8 languages.

MUESCA PRO (one-time purchase at a launch price, 7-day free trial)
• Allow or deny Claude Code permission requests from the notch, with a preview of the command.
• Music controls and synced lyrics for what is playing.
• Tasks with reminders.
• A file shelf: drop files on the notch and drag them out later.
• The notch on every monitor.
• Interactive usage charts (tooltips, ranges, pace projection) and advanced focus (linked tasks, weekly stats, custom durations).
The trial starts the first time you open Muesca. When it ends, the Pro features lock without breaking anything: your tasks and shelf files are kept, read-only, until you buy Pro.

PRIVACY
Muesca runs on your PC. To read your quota it uses your local Claude Code sign-in and talks only to Anthropic; you can turn that off and read the quota from Claude Code's status line instead. It sends an anonymous daily usage count with no identifiers, which you can turn off in Settings. Synced lyrics send the song title and artist to lrclib.net. Your prompts, code and transcripts never leave your PC. Details in the privacy policy.

CLAUDE CODE INTEGRATION
Live sessions, permissions and the status line are optional. When you turn them on, Muesca adds its own entries to Claude Code's settings.json (after making a backup), and when you turn them off it removes only those. Before uninstalling Muesca, click "Remove Claude Code integration" in Settings: it takes out Muesca's hooks and status line in one go (with a backup) so Claude Code is left exactly as it was. If you forget, Claude Code keeps working: your status line does not depend on Muesca being installed.
