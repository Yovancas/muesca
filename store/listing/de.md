## Nombre
Muesca

## Subtítulo
Claude Code-Kontingent und Sitzungen in der Notch

## Descripción corta
Erfordert Claude Code. Sieh dein Claude Code-Kontingent (5 Stunden und wöchentlich), Live-Sitzungen und Berechtigungsanfragen in einer kleinen Notch oben am Bildschirm und im Infobereich. Kostenlos, mit optionalem Pro als Einmalkauf. Nicht mit Anthropic verbunden.

## Descripción
Erfordert Claude Code (die CLI oder die Desktop-App), installiert und angemeldet auf diesem PC. Muesca ist eine unabhängige App für Claude Code: Sie stammt nicht von Anthropic, ist nicht mit Anthropic verbunden und wird nicht von Anthropic unterstützt.

Muesca behält Claude Code für dich im Blick. Eine kleine Notch oben am Bildschirm und ein Symbol im Infobereich zeigen, wie viel deines Kontingents verbraucht ist, wann es zurückgesetzt wird und was jede deiner Claude Code-Sitzungen gerade macht, ohne dass du ins Terminal wechseln musst.

KOSTENLOS
• Das echte Kontingent der 5-Stunden- und der Wochenfenster (dieselben Werte, die Claude Code erhält), mit Countdown bis zum Zurücksetzen und Tempo.
• Ein Symbol im Infobereich, das Farbe und Form ändert, wenn du dich dem Limit näherst: auf einen Blick lesbar und farbenblindtauglich.
• Ein Panel mit Kontingentbalken, geschätzten Kosten pro Modell (auf deinem PC aus deinen Transkripten berechnet) und Nutzungsgrafiken.
• Hinweise bei 25, 50, 75 und 95 % oder wenn dein Tempo das Kontingent vor dem Zurücksetzen aufbrauchen würde.
• Eine Notch mit Kontingentringen und dem Status jeder Claude Code-Sitzung: arbeitet, wartet auf dich oder fertig.
• Eine Seite Nutzung mit allen Zahlen und ein Fokus-Timer (Pomodoro).
• Ein Willkommensassistent, ein interaktives Tutorial, helles und dunkles Design, Bewegung reduzieren und 8 Sprachen.

MUESCA PRO (Einmalkauf zum Einführungspreis, 7 Tage kostenlos testen)
• Berechtigungsanfragen von Claude Code direkt in der Notch erlauben oder ablehnen, mit Vorschau des Befehls.
• Musiksteuerung und synchronisierte Songtexte zu dem, was gerade läuft.
• Aufgaben mit Erinnerungen.
• Eine Dateiablage: Dateien auf die Notch ziehen und später wieder herausziehen.
• Die Notch auf jedem Monitor.
• Interaktive Nutzungsgrafiken (Tooltips, Zeiträume, Tempoprognose) und erweiterter Fokus (verknüpfte Aufgaben, Wochenstatistik, eigene Dauer).
Der Test beginnt beim ersten Öffnen von Muesca. Danach werden die Pro-Funktionen gesperrt, ohne dass etwas kaputtgeht: Deine Aufgaben und die Dateien in der Ablage bleiben erhalten, schreibgeschützt, bis du Pro kaufst.

DATENSCHUTZ
Muesca läuft auf deinem PC. Um dein Kontingent zu lesen, nutzt es deine lokale Claude Code-Anmeldung und spricht nur mit Anthropic; du kannst das abschalten und das Kontingent stattdessen aus der Statuszeile von Claude Code lesen. Es sendet einmal täglich eine anonyme Nutzungszählung ohne Kennung, die du in den Einstellungen abschalten kannst. Synchronisierte Songtexte senden Titel und Interpret an lrclib.net. Deine Prompts, dein Code und deine Transkripte verlassen deinen PC nie. Details in der Datenschutzerklärung.

INTEGRATION MIT CLAUDE CODE
Live-Sitzungen, Berechtigungen und die Statuszeile sind optional. Beim Einschalten fügt Muesca eigene Einträge in die settings.json von Claude Code ein (nach einer Sicherung) und entfernt beim Ausschalten nur diese. Klicke vor dem Deinstallieren von Muesca in den Einstellungen auf „Integration mit Claude Code entfernen“: Das entfernt die Hooks und die Statuszeile von Muesca in einem Schritt (mit Sicherung), damit Claude Code genau so bleibt, wie es war. Falls du es vergisst, funktioniert Claude Code weiter: Deine Statuszeile hängt nicht von Muesca ab.

Claude und Claude Code sind Marken von Anthropic, PBC.
