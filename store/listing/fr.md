## Nombre
Muesca

## Subtítulo
Quota et sessions Claude Code dans un notch

## Descripción corta
Nécessite Claude Code. Suivez votre quota Claude Code (5 heures et semaine), vos sessions en direct et les demandes d'autorisation dans un petit notch en haut de l'écran et dans la zone de notification. Gratuit, Pro facultatif en achat unique. Non affilié à Anthropic.

## Descripción
Nécessite Claude Code (la CLI ou l'application de bureau) installé et connecté sur ce PC. Muesca est une application indépendante pour Claude Code : elle n'est ni conçue par Anthropic, ni affiliée à Anthropic, ni approuvée par Anthropic.

Muesca surveille Claude Code pour vous. Un petit notch en haut de l'écran et une icône dans la zone de notification indiquent la part de votre quota déjà utilisée, quand il se réinitialise et ce que fait chacune de vos sessions Claude Code, sans passer par le terminal.

GRATUIT
• Le quota réel des fenêtres de 5 heures et hebdomadaire (les mêmes chiffres que reçoit Claude Code), avec le compte à rebours de la réinitialisation et le rythme.
• Une icône dans la zone de notification qui change de couleur et de forme à l'approche de la limite : lisible d'un coup d'œil et adaptée au daltonisme.
• Un panneau avec les barres de quota, la dépense estimée par modèle (calculée sur votre PC à partir de vos transcriptions) et des graphiques d'usage.
• Des alertes à 25, 50, 75 et 95 %, ou si votre rythme épuiserait le quota avant la réinitialisation.
• Un notch avec les anneaux de quota et l'état de chaque session Claude Code : en cours, vous attend ou terminée.
• Une page Utilisation avec tous les chiffres, et un minuteur de concentration (pomodoro).
• Un assistant de bienvenue, un tutoriel interactif, des thèmes clair et sombre, la réduction des animations et 8 langues.

MUESCA PRO (achat unique à prix de lancement, essai gratuit de 7 jours)
• Autoriser ou refuser les demandes d'autorisation de Claude Code depuis le notch, avec un aperçu de la commande.
• Commandes de musique et paroles synchronisées de ce qui est en lecture.
• Tâches avec rappels.
• Un bac à fichiers : déposez des fichiers sur le notch et faites-les glisser plus tard.
• Le notch sur chaque écran.
• Des graphiques d'usage interactifs (infobulles, plages, projection du rythme) et la concentration avancée (tâches liées, statistiques de la semaine, durées personnalisées).
L'essai commence la première fois que vous ouvrez Muesca. À la fin, les fonctions Pro se verrouillent sans rien casser : vos tâches et les fichiers du bac sont conservés, en lecture seule, jusqu'à l'achat du Pro.

CONFIDENTIALITÉ
Muesca fonctionne sur votre PC. Pour lire votre quota, il utilise votre connexion locale à Claude Code et ne communique qu'avec Anthropic ; vous pouvez le désactiver et lire le quota depuis la ligne d'état de Claude Code. Il envoie un comptage d'usage anonyme par jour, sans identifiant, désactivable dans les Paramètres. Les paroles synchronisées envoient le titre et l'artiste du morceau à lrclib.net. Vos prompts, votre code et vos transcriptions ne quittent jamais votre PC. Détails dans la politique de confidentialité.

INTÉGRATION AVEC CLAUDE CODE
Les sessions en direct, les autorisations et la ligne d'état sont facultatives. Quand vous les activez, Muesca ajoute ses propres entrées au fichier settings.json de Claude Code (après une sauvegarde) et, quand vous les désactivez, ne retire que celles-ci. Avant de désinstaller Muesca, cliquez sur « Retirer l'intégration avec Claude Code » dans les Paramètres : cela retire d'un coup les hooks et la ligne d'état de Muesca (avec une sauvegarde) pour que Claude Code reste exactement comme avant. Si vous oubliez, Claude Code continue de fonctionner : votre ligne d'état ne dépend pas de Muesca.

Claude et Claude Code sont des marques d'Anthropic, PBC.
