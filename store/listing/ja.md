## Subtítulo

## Descripción corta
Claude Code が必要です。Claude Code の使用量（5 時間と週間）、ライブセッション、権限リクエストを、画面上部の小さなノッチとシステムトレイで確認できます。無料。Pro は任意の買い切りアップグレードです。Anthropic とは関係ありません。

## Descripción
この PC に Claude Code（CLI またはデスクトップアプリ）がインストールされ、サインインしている必要があります。Muesca は Claude Code 向けの独立したアプリです。Anthropic が開発・提携・承認したものではありません。

Muesca は Claude Code を見守ります。画面上部の小さなノッチとシステムトレイのアイコンが、使用量の割合、リセットまでの時間、各 Claude Code セッションの状態を表示します。ターミナルに切り替える必要はありません。

無料
• 5 時間枠と週間枠の実際の使用量（Claude Code が受け取るのと同じ数値）、リセットまでのカウントダウンとペース。
• 上限に近づくと色と形が変わるトレイアイコン。ひと目で読めて、色覚の多様性にも配慮。
• 使用量バー、モデル別の推定コスト（トランスクリプトから PC 上で計算）、使用量グラフのパネル。
• 25、50、75、95 % を超えたとき、またはこのペースだとリセット前に使い切りそうなときの通知。
• 使用量リングと各 Claude Code セッションの状態（作業中、あなた待ち、完了）を表示するノッチ。
• すべての数値が見られる「使用量」ページと、集中タイマー（ポモドーロ）。
• ウェルカムアシスタント、インタラクティブなチュートリアル、ライト／ダークテーマ、アニメーションを減らす設定、8 言語。

MUESCA PRO（発売記念価格の買い切り、7 日間の無料体験）
• ノッチから Claude Code の権限リクエストを許可／拒否。コマンドのプレビュー付き。
• 再生中の音楽の操作と同期歌詞。
• リマインダー付きタスク。
• ファイルシェルフ：ファイルをノッチにドロップし、あとでドラッグして取り出せます。
• すべてのモニターにノッチ。
• インタラクティブな使用量グラフ（ツールチップ、期間、ペースの予測）と高度な集中機能（タスクとの連携、週間統計、時間のカスタマイズ）。
体験期間は Muesca を初めて開いたときに始まります。終了後、Pro 機能は何も壊さずにロックされます。タスクとシェルフのファイルは保持され、Pro を購入するまで読み取り専用になります。

プライバシー
Muesca はあなたの PC 上で動作します。使用量を読み取るためにローカルの Claude Code のサインイン情報を使い、通信先は Anthropic だけです。この機能はオフにでき、その場合は Claude Code のステータスラインから使用量を読み取ります。識別子を含まない匿名の利用カウントを 1 日 1 回送信します（設定でオフにできます）。同期歌詞は曲名とアーティスト名を lrclib.net に送信します。プロンプト、コード、トランスクリプトが PC の外に出ることはありません。詳しくはプライバシーポリシーをご覧ください。

CLAUDE CODE との連携
ライブセッション、権限、ステータスラインは任意です。オンにすると、Muesca はバックアップを作成してから Claude Code の settings.json に独自のエントリを追加し、オフにするとそのエントリだけを削除します。Muesca をアンインストールする前に、設定で「Claude Code との連携を解除」をクリックしてください。Muesca のフックとステータスラインを一度に削除し（バックアップあり）、Claude Code が元のとおりに戻ります。忘れても Claude Code はそのまま動作し、お使いのステータスラインは Muesca がなくても表示されます。

Claude および Claude Code は Anthropic, PBC の商標です。
