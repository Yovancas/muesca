## Nombre
Muesca

## Subtítulo
在瀏海中查看 Claude Code 用量與工作階段

## Descripción corta
需要 Claude Code。在螢幕頂端的小瀏海與系統匣中查看 Claude Code 用量（5 小時與每週）、即時工作階段和權限要求。免費，另有選購的一次性買斷 Pro。與 Anthropic 無關。

## Descripción
這部電腦上必須已安裝並登入 Claude Code（CLI 或桌面應用程式）。Muesca 是 Claude Code 的獨立應用程式：並非由 Anthropic 開發，也與 Anthropic 沒有隸屬或背書關係。

Muesca 幫你留意 Claude Code。螢幕頂端的小瀏海與系統匣圖示會顯示你用了多少額度、何時重設，以及每個 Claude Code 工作階段正在做什麼，不必切換到終端機。

免費
• 5 小時與每週時段的實際用量（與 Claude Code 收到的數字相同），附重設倒數與使用速度。
• 接近上限時會改變顏色與形狀的系統匣圖示：一眼就能看懂，也照顧色覺差異。
• 面板中有額度長條、各模型的估計花費（在你的電腦上根據對話紀錄計算）與用量圖表。
• 超過 25、50、75、95 % 時，或照目前速度會在重設前用完時提醒你。
• 瀏海顯示額度圓環與每個 Claude Code 工作階段的狀態：工作中、等你回應或已完成。
• 包含所有數字的「用量」頁面，以及專注計時器（番茄鐘）。
• 歡迎精靈、互動式教學、淺色與深色主題、減少動態效果，以及 8 種語言。

MUESCA PRO（上市優惠價一次性買斷，7 天免費試用）
• 直接在瀏海中允許或拒絕 Claude Code 的權限要求，並預覽指令。
• 正在播放的音樂控制與同步歌詞。
• 附提醒的工作。
• 檔案架：把檔案放到瀏海上，之後再拖出來。
• 每部螢幕都有瀏海。
• 互動式用量圖表（工具提示、時間範圍、速度預測）與進階專注功能（連結工作、每週統計、自訂時長）。
試用期會在你第一次開啟 Muesca 時開始。試用結束後，Pro 功能會鎖定但不會破壞任何東西：你的工作與檔案架中的檔案都會保留，在購買 Pro 之前為唯讀。

隱私權
Muesca 在你的電腦上執行。為了讀取用量，它會使用你本機的 Claude Code 登入資訊，並且只與 Anthropic 通訊；你可以關閉此功能，改從 Claude Code 的狀態列讀取用量。它每天會傳送一次不含任何識別碼的匿名使用次數，可在設定中關閉。同步歌詞會將歌曲名稱與演出者傳送到 lrclib.net。你的提示、程式碼與對話紀錄都不會離開你的電腦。詳情請參閱隱私權政策。

與 CLAUDE CODE 整合
即時工作階段、權限與狀態列都是選用功能。開啟後，Muesca 會先建立備份，再將自己的項目加入 Claude Code 的 settings.json；關閉時只會移除這些項目。解除安裝 Muesca 之前，請在設定中按「移除與 Claude Code 的整合」：一次移除 Muesca 的 hooks 與狀態列（會先備份），讓 Claude Code 完全恢復原狀。就算忘了，Claude Code 也能照常運作：你的狀態列不依賴 Muesca。

Claude 與 Claude Code 是 Anthropic, PBC 的商標。
