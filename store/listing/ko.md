## Nombre
Muesca

## Subtítulo
Claude Code 사용량과 세션을 노치에서

## Descripción corta
Claude Code가 필요합니다. Claude Code 사용량(5시간 및 주간), 실시간 세션, 권한 요청을 화면 위쪽의 작은 노치와 시스템 트레이에서 확인하세요. 무료이며, 선택 사항인 Pro는 한 번만 구매하면 됩니다. Anthropic과 관련이 없습니다.

## Descripción
이 PC에 Claude Code(CLI 또는 데스크톱 앱)가 설치되어 있고 로그인되어 있어야 합니다. Muesca는 Claude Code를 위한 독립 앱으로, Anthropic이 만들거나 제휴하거나 보증한 앱이 아닙니다.

Muesca가 Claude Code를 대신 지켜봅니다. 화면 위쪽의 작은 노치와 시스템 트레이 아이콘이 사용량, 초기화 시점, 각 Claude Code 세션이 무엇을 하고 있는지 알려 주므로 터미널로 전환할 필요가 없습니다.

무료
• 5시간 및 주간 창의 실제 사용량(Claude Code가 받는 것과 같은 수치), 초기화까지 남은 시간과 속도.
• 한도에 가까워질수록 색과 모양이 바뀌는 트레이 아이콘: 한눈에 읽을 수 있고 색각 이상에도 맞춰져 있습니다.
• 사용량 막대, 모델별 예상 비용(PC에서 트랜스크립트로 계산), 사용량 그래프가 있는 패널.
• 25, 50, 75, 95 %를 넘을 때나 지금 속도로는 초기화 전에 다 쓸 것 같을 때 알림.
• 사용량 링과 각 Claude Code 세션의 상태(작업 중, 당신을 기다리는 중, 완료)를 보여 주는 노치.
• 모든 수치가 있는 사용량 페이지와 집중 타이머(뽀모도로).
• 환영 도우미, 대화형 튜토리얼, 밝은 테마와 어두운 테마, 동작 줄이기, 8개 언어.

MUESCA PRO(출시 기념가의 일회성 구매, 7일 무료 체험)
• 노치에서 Claude Code 권한 요청을 허용 또는 거부하고 명령을 미리 볼 수 있습니다.
• 재생 중인 음악의 컨트롤과 동기화 가사.
• 알림이 있는 작업.
• 파일 선반: 파일을 노치에 놓아 두었다가 나중에 끌어서 꺼낼 수 있습니다.
• 모든 모니터에 노치.
• 대화형 사용량 그래프(도구 설명, 기간, 속도 예측)와 고급 집중 기능(작업 연결, 주간 통계, 원하는 시간 설정).
체험은 Muesca를 처음 열 때 시작됩니다. 체험이 끝나면 Pro 기능이 아무것도 망가뜨리지 않고 잠깁니다. 작업과 선반의 파일은 그대로 남으며, Pro를 구매할 때까지 읽기 전용이 됩니다.

개인 정보
Muesca는 PC에서 실행됩니다. 사용량을 읽기 위해 로컬 Claude Code 로그인 정보를 사용하며 Anthropic과만 통신합니다. 이 기능은 끌 수 있으며, 그러면 Claude Code 상태 표시줄에서 사용량을 읽습니다. 식별자가 없는 익명 사용 횟수를 하루에 한 번 보내며, 설정에서 끌 수 있습니다. 동기화 가사는 곡 제목과 아티스트를 lrclib.net에 보냅니다. 프롬프트, 코드, 트랜스크립트는 PC 밖으로 나가지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

CLAUDE CODE 연동
실시간 세션, 권한, 상태 표시줄은 선택 사항입니다. 켜면 Muesca가 백업을 만든 뒤 Claude Code의 settings.json에 자체 항목을 추가하고, 끄면 그 항목만 제거합니다. Muesca를 제거하기 전에 설정에서 「Claude Code 연동 제거」를 눌러 주세요. Muesca의 훅과 상태 표시줄을 한 번에 제거하고(백업 포함) Claude Code를 원래 상태 그대로 둡니다. 잊어버려도 Claude Code는 계속 작동하며, 사용자의 상태 표시줄은 Muesca가 없어도 표시됩니다.

Claude 및 Claude Code는 Anthropic, PBC의 상표입니다.
