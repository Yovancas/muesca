# Marca: Muesca (by Bekay)

- `muesca.svg`: el logo vectorial, fuente de todo lo demás.
- `muesca.ico`: icono de la app (16-256 px).
- `muesca-<n>.png`: PNG cuadrados de 16 a 1024 px para la Store, el instalador y el README.
- `muesca-wide-310x150.png` / `muesca-splash-620x300.png`: mosaico ancho y splash del MSIX.
- `muesca-wordmark.png` / `muesca-wordmark-dark.png`: logotipo con el nombre, para fondo claro y oscuro.

Colores: degradado violeta `#7B4DFF` → azul `#1F6FFF`, negro `#0A0A12` y anillo `#B49BFF` → `#4C9BFF`.
Tipografía del logotipo: Space Grotesk (licencia OFL).
